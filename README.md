# PowerBI_Project01_UKBANKCUSTOMERS

📊 Project Overview
This project showcases my first Power BI dashboard built using a publicly available UK bank customer dataset. It highlights my ability to clean, model, and visualize data to extract meaningful insights.

🔧 Tools & Skills Used
Power BI
Power Query
Data Cleaning
Data Modeling
Interactive Visualizations
Data Analysis

🧠 Key Insights
Distribution of customers by region, gender, and age.
Patterns in account balance and credit score.
Identification of potential high-value customers.
Trends in customer churn risk.

🎯 Objective
To gain hands-on experience in building end-to-end data visualization solutions with Power BI. This project helped reinforce my understanding of transforming raw datasets into clear, business-ready dashboards that support data-driven decision-making.

📂 Dataset
A sample dataset representing UK bank customer details (synthetic data used for educational purposes).
